# Diagrams

Excalidraw diagrams at `diagrams/<topic>/<slug>.excalidraw`, with an exported `<slug>.svg` next to each one so notes can embed it.

- Start from [the blank diagram](../templates/blank.excalidraw).
- Commit both the `.excalidraw` source and the exported `.svg`; re-export after every edit.
- When exporting, turn on "Embed scene" if you want the `.svg` itself to be re-openable in Excalidraw.
